【典例6】粗糙斜面（37°，μ=0.5）上物块匀速上滑 —— 求方向可变的外力 F 的最小值

A.（✗ 错误）4√5 N ≈ 8.94 N　比最小值还小：由 F = 20/(cosθ+0.5sinθ) ≥ 20/(√5/2) = 8√5 N，无论 F 什么方向都不可能。
B.（✓ 正确）8√5 N ≈ 17.9 N　当 θ = arctan μ = arctan 0.5 ≈ 26.6°（此时 Fₙ = 8 N、f = 4 N）时分母最大，F 最小。
C.（✗ 错误）12 N　12 N 只是重力沿斜面分量 mg sin37°；还需克服摩擦，且 12 N < Fₖₙₚ = 8√5 N，不可能。
D.（✗ 错误）16 N　16 N = mg cos37°，仍小于 Fₖₙₚ = 8√5 ≈ 17.9 N，不可能。
答案：B　　Fₖₙₚ = mg(sin37° + μcos37°)/√(1+μ²) = 20 ÷ (√5/2) = 8√5 N ≈ 17.9 N（方向与斜面成 arctan 0.5 ≈ 26.6°） 　注意：θ > 53.1° 时 Fₙ < 0，物块脱离斜面，"匀速上滑"不成立，该区间无解。
