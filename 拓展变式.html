【拓展变式】水平缓拉半圆柱 A 直至 C 恰好落地 —— 求地面动摩擦因数最小值 μmin（B 全程静止）

第 1 步 · 几何关系　三圆柱半径均为 R，彼此外切 ⇒ 圆心距 OₖOₚ = 2R。设 OₖOₚ 与竖直方向夹角 θ，则 Oₚ 离地高度 = 2R·cosθ。 初始 A、B 相靠（OₖOₙ = 2R）⇒ θ₀ = 30°；C 恰好落地 ⇔ 2R·cosθ = R ⇒ θ = 60°。整个过程中 θ 由 30° 增大到 60°。
第 2 步 · 对 C 平衡（缓慢移动）　两段弹力 F 对称、沿圆心连线，竖直方向：2F·cosθ = mg ⇒ F = mg/(2cosθ)。 θ 增大 ⇒ cosθ 减小 ⇒ F 增大（√3mg/3 ≈ 0.577mg → mg）；C 恰落地时 B 受 C 压力的水平分力最大，此时 θ = 60°。
第 3 步 · 对 B（始终静止）　每个半圆柱重 mg/2。水平：f = F·sinθ = (mg/2)·tanθ（随 θ 增大）； 竖直：Fₙ = mg/2 + F·cosθ = mg/2 + mg/2 = mg（与 θ 无关，恒定！——因为 F·cosθ = mg/2 始终成立）。
第 4 步 · 不滑动条件　最大静摩擦 ≈ 滑动摩擦：f ≤ μFₙ ⇒ μ ≥ f/Fₙ = tanθ/2。 θ = 60° 时要求最大 ⇒ μmin = tan60°/2 = √3/2。
